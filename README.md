# AryaVoipe

Private, audio-only team calling platform built for browser and desktop extension use.

## Phase 1

- Cloudflare Workers API
- Cloudflare D1 database
- Durable Objects signaling
- WebRTC audio-only calls
- Browser/extension-friendly UI
- Basic authentication and presence

## Local development

```bash
npm install
npm run dev
```
